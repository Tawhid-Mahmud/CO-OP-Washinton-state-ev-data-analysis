# Washington State EV Dealership Analysis

A web-based analysis tool for evaluating the electric vehicle market in Washington State, specifically designed for potential EV dealership investors.

LIVE WEB PAGE [https://github.com/Tawhid-Mahmud/CO-OP-Washinton-state-ev-data-analysis](https://resplendent-froyo-f7e3f2.netlify.app/)

## Overview

This project provides a comprehensive analysis of the EV market in Washington State, focusing on:
- Current market growth and trends
- Strategic location analysis
- Investment recommendations
- Interactive data visualizations

## Key Features

- Market Analysis Dashboard
- Interactive Data Visualizations
- Location-based Recommendations
- Investment Strategy Insights

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tableau Visualizations

## Project Structure

```
├── index.html          # Main webpage
├── styles.css          # Styling
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## Usage

1. Open `index.html` in a web browser
2. Navigate through the sections to view:
   - Market Overview
   - Data Visualizations
   - Investment Recommendations

## Data Source

Data sourced from the Washington State Department of Licensing (DOL) regarding Battery Electric Vehicles (BEVs) and Plug-In Hybrid Electric Vehicles (PHEVs) registrations. The dataset used is "Electric_Vehicle_Population_Data_20250402.csv" from the Washington State Department of Licensing, which contains detailed information about EV registrations across the state.
